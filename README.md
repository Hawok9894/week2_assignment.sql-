
# Week 2 Assignment: Introduction to SQL

## Description
This assignment demonstrates basic SQL queries using the sales database.

## Questions Covered
1. Retrieve payment information.
2. Find orders with status In Process and sort by order date.
3. Find Sales Representatives and sort by employee number.
4. Retrieve all records from the offices table.
5. Retrieve the five cheapest products.

## Skills Practiced
- SELECT
- WHERE
- ORDER BY
- LIMIT
- Retrieving data from multiple tables
